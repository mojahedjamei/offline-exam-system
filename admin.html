The CSV content should already be in the selected language. This setting controls the exam interface, buttons, and text direction.

Students get a button that sends their result through the system share sheet when the browser allows it (needs HTTPS, e.g. GitHub Pages). Otherwise the result is downloaded, a summary is copied, and this link (or the selected app) is opened. Messenger apps cannot be given a file by a link, so the file is attached manually in that case.

CSV format (first row is header):
text, optionA, optionB, optionC, optionD, correct, explanation

Column correct: 0 = A, 1 = B, 2 = C, 3 = D. Also accepts A–D letters and Persian/Arabic digits.
Column explanation: optional.
Delimiter: comma or semicolon (auto-detected).
Encoding: save as CSV UTF-8.
