================================================================
  OFFLINE EXAM SYSTEM — COMPLETE GUIDE
  For Teachers and Students
================================================================

This system runs entirely in the browser. No internet, no server,
and no installation are required. The teacher uses one file to
create the exam, and students use the generated file to take it.

----------------------------------------------------------------
  FILES
----------------------------------------------------------------

  admin.html             The teacher's panel. Used to build the exam.
  index.html              Redirects to admin.html.
  samples/                Example CSV files (en, fa, ar).
  exam_<title>_<ts>.html  Generated by admin.html. Students take this.
  result_<id>_<ts>.json   Generated by the exam file after completion.
  LICENSE                 MIT license.
  README.md               Full documentation.
  GUIDE.txt               This file.

Only admin.html is required. Everything else is produced by it.

================================================================
  TEACHER GUIDE
================================================================

STEP 1 — OPEN THE TEACHER PANEL
  Open admin.html in any modern browser (Chrome, Edge, Firefox,
  Safari). It runs fully offline.

STEP 2 — PREPARE THE QUESTION BANK (CSV FILE)
  You can either:
    a) Click "Download sample CSV" to get a ready-to-edit file.
    b) Create your own CSV with these columns in the first row:

       text,optionA,optionB,optionC,optionD,correct,explanation

    Column meanings:
      text         The question itself.
      optionA      First choice.
      optionB      Second choice.
      optionC      Third choice.
      optionD      Fourth choice.
      correct      The correct answer:
                     0 = A, 1 = B, 2 = C, 3 = D.
                     Persian/Arabic digits (۰-۳, ٠-٣) are accepted.
      explanation  Optional. Shown in the result file.

  When saving from Excel, use:
    File > Save As > CSV UTF-8 (Comma delimited).
  Do NOT save as .xlsx.
  Do NOT use ANSI/Windows-1256 encoding.

  Delimiter: the tool auto-detects "," or ";".

  TIP: If a question contains a comma, wrap the cell in quotes:
       "Which one is correct, and why?"

  IMPORTANT: The CSV content must already be in the target
  language (English, Persian, or Arabic). This tool does NOT
  translate content, because it runs fully offline.

STEP 3 — CONFIGURE THE EXAM
  In admin.html, fill in:
    - Question bank file (CSV): Upload your CSV.
    - Exam title: e.g. WordPress Fundamentals.
    - Output language: English / Persian / Arabic.
      This controls the UI text and direction (LTR/RTL).
    - Number of questions: How many each student will see
      (drawn randomly from the bank).
    - Duration (minutes): Countdown timer (1 to 600).
    - Pass mark (%): 0 to 100. Default 50.
    - Share network and class link (optional): used when a
      student sends the result. Telegram, WhatsApp, Bale,
      Rubika, Eitaa or the system share sheet.
    - Save a copy of the exam file to Downloads (on/off).
    - Students: also save a copy of the result file (on/off).
    - Shuffle answer options per student (on/off).
    - Show correct answers after finishing (on/off).

  Then click "Generate exam file".

  If some rows were skipped (invalid "correct" value or empty
  options), a warning will list the affected row numbers.

STEP 4 — DISTRIBUTE THE EXAM
  The browser downloads a file named exam_<title>_<timestamp>.html.
  This file is fully self-contained. Send it to students via:
    - Telegram / WhatsApp
    - Email
    - Google Drive / Dropbox
    - Any class portal or LMS

  No further action is required from you.

================================================================
  STUDENT GUIDE
================================================================

STEP 1 — OPEN THE EXAM FILE
  Download exam_<title>_<timestamp>.html and open it in a browser
  (phone or computer).

STEP 2 — ENTER YOUR DETAILS
  Type your full name and student ID, then click "Start Exam".

STEP 3 — ANSWER THE QUESTIONS
  A countdown timer is shown at the top.
    - If time runs out, the exam ends automatically.
    - You can also click "End Exam" to finish early.
    - You can flag questions for later review.
    - If you reload the page, your progress is restored.

STEP 4 — SAVE YOUR RESULT
  When the exam is done, three buttons appear:
    - Download Result (JSON)
    - Share Result
    - Copy Result
  Use whichever works on your device. Send the result file
  back to your teacher through the same channel you received
  the exam from.
  Share Result attaches the file directly only on HTTPS pages.
  Otherwise it downloads the file, copies a summary and opens
  the class link or messenger: attach the file there manually.

================================================================
  RESULT FILE (WHAT THE TEACHER RECEIVES)
================================================================

Each student returns a JSON file containing:
  - Student name and ID
  - Exam title and exam language
  - Total questions, correct answers, score (0-100)
  - Pass mark and pass/fail status
  - Start time, finish time, duration in seconds
  - Full list of questions with:
      * A question ID (numbered in the order of valid CSV rows)
      * The student's answer
      * The correct answer
      * Whether it was correct
      * The explanation

The teacher can open the JSON in a text editor or combine
multiple files into Excel / Power BI for class-wide analysis.

For Excel: Data > Get Data > From File > From JSON.

WARNING: If a student name starts with =, +, -, or @,
prefix it with a single quote before pasting into Excel
to avoid spreadsheet formula injection.

================================================================
  TROUBLESHOOTING
================================================================

  Problem: The CSV won't load.
  Solution: Make sure it is saved as "CSV UTF-8", not .xlsx.

  Problem: Some questions are missing.
  Solution: Check the warning message. Rows with an invalid
            "correct" value or empty options are skipped.
            Persian/Arabic digits are accepted.

  Problem: The generated exam looks blank.
  Solution: Open it in Chrome, Edge, Firefox, or Safari
            (latest versions).

  Problem: Persian/Arabic text shows left-aligned.
  Solution: Regenerate the exam and confirm the output
            language is set to Persian or Arabic.

  Problem: A student's result file won't open.
  Solution: JSON files can be opened with any text editor
            (Notepad, VS Code) or imported into Excel/Power BI.

  Problem: The result file couldn't be downloaded on iOS.
  Solution: Use the "Share Result" or "Copy Result" button.

================================================================
  SECURITY NOTES
================================================================

This system is designed for low-stakes, offline assessments
where trust already exists between teacher and student.

  - The question bank and correct answers are embedded in the
    student's file. A technically skilled student could extract
    them by inspecting the file.

  - Result JSON files are plain text and can be edited before
    sending. They are NOT tamper-proof.

  - If stronger integrity is required (anti-cheat, live monitoring,
    centralized storage), a local server architecture
    (e.g. Django + WebSocket) is needed.
